Как считается

Геометрия. Площадь наплавленного металла считается по форме разделки: зазор b·s, скосы (s−c)²·tg(α/2), усиление 0,73·e·g, где e — ширина шва, g — высота усиления. Для углового шва 1,15·k²/2 с учётом выпуклости, для тавра со скосом добавляется треугольник скоса.

Проходы. Площадь корневого прохода и заполняющего прохода по положениям берутся из справочника режимов для выбранной группы материала и диаметра проволоки.

Режимы. Ток прохода берётся из справочника по типу прохода и положению и ограничивается на тонком металле. Скорость подачи и напряжение — линейные синергетические зависимости Vпп = a·I + b, U = c + e·I из справочника; для сталей они получены по 34 проходам аттестованных WPS EWM. Скорость сварки выводится из баланса металла: v = Vпп·Sпров·η / Sпрохода.

Погонная энергия по EN 1011-1: Q = 0,8·U·I / v, кДж/мм.

Подогрев. Для сталей — метод CET (EN 1011-2, прил. C) с HD = 4 мл/100 г; если в справочнике материала задан минимальный подогрев, берётся большее значение. Для нержавеющих сталей подогрев не нужен, контролируется межпроходная температура. Для алюминия рекомендуется подогрев 60–100 °C при толщине от 15 мм.

Расход. Масса наплавки = площадь × плотность материала (сталь 7,85, нержавеющая 7,9, алюминий 2,7 г/см³) с учётом коэффициента использования проволоки.

Все значения ориентировочные и служат стартовой точкой. Рабочие режимы подтверждаются пробной сваркой и аттестацией технологии (pWPS → WPQR по ISO 15614-1/-2 или по правилам НАКС).
